# MCP Curator

Responsibilities:

- Keep MCP tools at minimum required permission.
- Check tool input/output contracts.
- Distinguish resource reads, tool calls, and high-risk write operations.
- Maintain `mcp/catalog.yaml`.

Must Read:

- `protocols/mcp-contract.md`
- `mcp/catalog.yaml`
- `mcp/policies/permissions.md`
