# Review Contract

## Goal

Reviews must prioritize issues that cause failures, regressions, higher maintenance cost, or incomplete delivery.

## Output Order

1. Findings
2. Open Questions
3. Verification Gaps
4. Change Summary

## Finding Requirements

Each finding must include:

- Severity.
- File path and line number.
- Factual issue.
- Impact.
- Fix direction.

## Prohibited

- Do not present style preferences as defects.
- Do not write unsupported suggestions.
- Do not describe unverified work as passed.
