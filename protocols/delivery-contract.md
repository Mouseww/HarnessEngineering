# Delivery Contract

## Pre-Delivery Gate

The agent must have:

- Clear change scope.
- Fresh verification command and output.
- Uncovered risks.
- Whether user follow-up is required.
- Whether memory or wiki was updated.

## Delivery Notes

Must include:

- Change summary.
- Verification results.
- Residual risks.
- Key files.

## Prohibited

- Claiming completion without verification.
- Hiding failed commands.
- Committing, pushing, or releasing without authorization.
